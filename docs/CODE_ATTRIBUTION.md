# Code Attribution

This document records the origins of the algorithms, libraries, and external
references used in the Sentinel Drift Engine, in the interest of transparency.

## Authorship

Author and architect: **Stiven Ntoktorov** (FinTech/ML Full-Stack Developer).
All architectural decisions, algorithm selection, scenario design, validation
methodology, and integration were directed by the author. AI pair-programming
assistance (Anthropic Claude) was used for implementation and code review, as
is standard practice in modern software development. Using an AI assistant does
not transfer authorship of the design; the engineering judgement — which
algorithm fits which problem, how to validate it, how to interpret the numbers —
is the author's.

## Algorithms — primary sources

| Module | Algorithm | Source |
|---|---|---|
| `bocpd.py` | Bayesian Online Changepoint Detection (run-length posterior, Normal-Inverse-Gamma conjugate predictive) | Adams & MacKay (2007), *Bayesian Online Changepoint Detection*, arXiv:0710.3742 |
| `velocity.py` | KL divergence between Gaussians; drift as its time-derivative | Kullback & Leibler (1951), *On Information and Sufficiency*, Annals of Mathematical Statistics |
| `contagion.py` | Personalized PageRank with a sanctioned-seed teleport vector | Page, Brin, Motwani & Winograd (1999), *The PageRank Citation Ranking*; implemented via NetworkX `pagerank` |
| `causal.py` | Likelihood-ratio test between two generative hypotheses | Classical Neyman-Pearson hypothesis testing |
| `stability.py` | Coefficient-of-variation anomaly vs cohort; product of two factors | Standard statistical-process-control reasoning |
| `cascade.py` | Information-economics escalation (expected value of analysis) | Value-of-Information theory — Howard (1966), *Information Value Theory*, IEEE |
| `public_intel.py` | Confirmation Lift (temporal co-occurrence of independent evidence) | Bayesian evidence combination (noisy-OR style joint) |
| `timetravel.py` | As-of replay leveraging the online (causal-by-construction) nature of BOCPD | Original composition over the BOCPD property |

## Regulatory and domain references

- FINMA Circular 2024/3, *Operational risks and resilience — banks* — human-in-the-loop and audit rationale.
- FATF (2023), *Guidance on Beneficial Ownership of Legal Persons* — ownership-topology risk rationale.
- Basel Committee (2024), *Sound management of risks related to money laundering and financing of terrorism*.

## Data

All customer data in this project is **synthetic**, generated by
`backend/app/drift/simulator.py` with deterministic seeds and known ground-truth
labels. No real customer data is used. Public signals (news, sanctions, adverse
media) are simulated; a production deployment would license real feeds
(e.g. Dow Jones Factiva, Refinitiv World-Check, corporate registries).
